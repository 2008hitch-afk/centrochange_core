# Simulazione Videocitofono Centro Change

**Solo dimostrazione statica/offline — zero operazioni reali.**

## Avvio
1. Su GitHub aprire [intercom-demo.html](intercom-demo.html) dal ramo plan/intercom-software-simulation-20261009.
2. Usare **Download raw file** (su repository privato, serve autenticazione), poi aprire il file scaricato con un browser su PC.
3. Digitare utente **demo** e password **demo**: credenziali inventate per la demo, non connesse a Centro Change.
4. Simulare una persona che suona, vedere l'anteprima grafica fittizia e premere audio/apriporta simulati.
5. Cambiare i checkbox «presente in Wi-Fi» e «autorizzato» per verificare come dovrebbero cambiare i permessi.

## Cosa dimostra e cosa NON dimostra

Mostra in modo cliccabile un **flusso di navigazione UX** per un professionista. NON include autenticazione sicura, chiamate a API, presenza Wi-Fi reale, notifiche push native, microfono, audio/video, Comelit, apertura porte o salvataggio dati. Nessuna richiesta a Internet o scrittura su disco è prevista dal file HTML.

Prima di scrivere software reale, leggere [masterplan](../VIDEOCITOFONO-SOFTWARE-MASTERPLAN-2026-10-09.md) e [handoff Codex](../VIDEOCITOFONO-CODEX-HANDOFF-2026-10-09.md).
