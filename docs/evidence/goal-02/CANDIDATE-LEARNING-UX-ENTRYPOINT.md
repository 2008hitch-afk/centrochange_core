# Test an operation from the user's actual entry point

A technically working operation may remain unusable when its entry point is nested under a label that users interpret as a different report. Acceptance should start from the user's normal landing view and verify that the intended action is discoverable without a technical URL. Then verify that human-readable selection labels still submit exact canonical identifiers and preserve server-side authorization.

This is a sanitized candidate pattern. It contains no customer identity, data, credentials or production claim. HITCH review is required before any generalized promotion.
