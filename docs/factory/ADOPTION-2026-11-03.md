## Ambito e precedenza

EMPV descrive **come sviluppare**, non sostituisce i requisiti HC-0005, il backend Frappe/ERPNext, la Product Identity o i gate di Centro Change. Le dieci skill EMPV affiancano le due già presenti. Non eseguire `bootstrap` su questo repository esistente. I vecchi Goal restano registrati nelle Issue/decisioni storiche; `factory/state.json` parte senza Goal perché **AUDIT-11 non è ancora autorizzato**.

Un nuovo Goal si aggiunge con `python3 scripts/goal_factory.py add-goal --root . --id GOAL-ID --title "..." --outcome "..." --type FEATURE --issue-ref github:...`, **solo dopo** la relativa Issue e decisione Owner. L'azione lo crea in stato PLANNED: l'autorizzazione operativa non deriva dal comando o dal JSON. Usare `python3 scripts/goal_factory.py status --root .` e `validate-project --root .` per ispezionare i dati dichiarativi. Non usare `doctor` sul runner copiato: quel comando è specifico del repository originale EMPV e dei suoi template.

## Live Preview + QA sintetico in worktree isolato Linux/WSL

Dove il lavoro è autorizzato, con Python, Node, dipendenze npm e browser Playwright disponibili:

```bash
cp factory/dev-feedback.example.json factory/dev-feedback.json
cd frontend/premium && npm ci --ignore-scripts --no-audit --no-fund && cd ../..
python3 scripts/dev_feedback.py doctor
```

Terminale A: `python3 scripts/dev_feedback.py preview` — Vite normale su `127.0.0.1:5182`, interrompibile con Ctrl+C.

Terminale B: `python3 scripts/dev_feedback.py check`, `python3 scripts/dev_feedback.py test --suite typecheck`, `python3 scripts/dev_feedback.py test --suite ui`.

La suite `ui` usa `playwright.feedback.config.ts` e un **secondo server sintetico su 5183**, per non contaminare la preview 5182. Non modifica le configurazioni Playwright della CI ufficiale. I test 5183 sono mock/sintetici; non dimostrano autenticazione, permessi o persistenza Frappe.

Sul PC Windows si può usare un tunnel SSH verso un **server di sviluppo autorizzato**:

```powershell
ssh -N -L 5182:127.0.0.1:5182 utente@host-di-sviluppo
```

Aprire `http://127.0.0.1:5182/assets/centrochange_core/premium/`. L'anteprima React autonoma non diventa per questo una sessione Frappe autenticata. Non esporre Vite pubblicamente.

## Regole di lavoro

Un solo Goal autorizzato → criterio di accettazione indipendente dal codice → modifica UI/API → preview e test mirati → diagnosi e correzione automatica da Codex → test integrati in clone Frappe solo con gate specifico → CI completa → reviewer indipendente → unico walkthrough Owner. Non confondere `PASS_LOCAL`, `PASS_LIVE` e `OWNER_ACCEPTED`.

**Nessuna esecuzione di AUDIT-11, merge, deploy STAGING/produzione, modifica DB/schema/ruoli o dati reali è autorizzata dalla presente adozione.**
